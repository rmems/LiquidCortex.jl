# Machine Interoception Benchmark v1

Deterministic replay of held-out telemetry sessions through memoryless baselines and
LiquidCortex reservoirs. Design, timebase contract and metric definitions are in
[`docs/machine-interoception.md`](../../docs/machine-interoception.md). Evaluation only — it
never controls a host.

## One command

From the repository root (CUDA GPU optional; without one the reservoir sections are skipped
and the result says so):

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. examples/interoception/replay.jl \
    --config examples/interoception/config.example.toml --out result.json
```

Flags: `--seed N` overrides the config seed, `--no-gpu` runs the baselines only. The run on the
bundled fixture takes about 40 s on an RTX 5080.

`result.json` contains the dataset/session manifest and hash, partitions, feature list and
train-only normalization, the timebase, model configuration (`config`), baseline and
LiquidCortex metrics, `systems` (device, VRAM, neurons, non-zeros, ms per step), the seed and
the git commit.

## Files

| File | Role |
|---|---|
| `replay.jl` | entry point and `InteroceptionBenchmark` module |
| `timebase.jl` | Phase 0: source/replay cadence, resampling, `τ_m` conversion |
| `dataset.jl` | CSV loading, session splits, normalization, supervisor policy, windowing |
| `baselines.jl` | ridge, small MLP, online NLMS readout |
| `reservoir.jl` | `SparseBrain` / `EnsembleBrain` replay and feature extraction |
| `metrics.jl` | MAE/RMSE, lead time, calibration, macro F1, false-safe rate |
| `make_fixture.jl` | regenerates `fixtures/` (synthetic, deterministic) |
| `config.example.toml` | documented configuration |

## Data

`fixtures/` holds six **synthetic** 24 s sessions at 100 ms (not hardware data), generated by
`make_fixture.jl`. Do not commit real telemetry. Point `[dataset] dir` at a local directory of
per-session CSVs (`t_ms` plus the canonical columns); see the "Real data" section of the design
note for mapping `rmems/gaming-telemetry` exports.

## Tests

```bash
julia --project=. test/interoception_tests.jl      # or the full suite: Pkg.test()
```

CPU-safe cases (timebase, dataset contract, splits, leakage, metrics, baselines) always run;
the replay case needs a CUDA device.
