# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `Project.toml` on `main` | yes |
| older untagged `0.2.0` snapshots | no |

There is no registered release yet. Treat `main` as the supported line.

## Reporting a vulnerability

Please use GitHub's private
[Security Advisories](https://github.com/rmems/LiquidCortex.jl/security/advisories/new).

Do not open a public issue for a vulnerability.

In scope: CUDA artifact resolution, workflow secrets, and the self-hosted GPU runner.
